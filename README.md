# ソフトの概要
気象庁やUSGSから震源などの情報を取得し、地図やリストに表示します。

## データ元
・気象庁
[震央分布](https://www.jma.go.jp/bosai/map.html#contents=hypo)、[震源データ](https://www.data.jma.go.jp/eqev/data/daily_map/)、 

・ＵＳＧＳ
[USGSの地震情報](https://earthquake.usgs.gov/earthquakes/map/)

## 使用したツールなど
Claude、Codex

# 注意点
当ソフト内で計算された数値などを取り扱う際は、情報が誤ってる可能性にも留意して取り扱うようにしてください
